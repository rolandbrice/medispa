# GUIDE GESTION — pour l'équipe MEDI-SPA (sans développeur)

## Modifier le site depuis le téléphone (2 min)
1. Allez sur **votresite.sn/admin** (mot de passe donné à l'installation).
2. **« 1 · Infos générales »** : téléphone, WhatsApp, horaires, adresse, note Google.
3. **« 2 · Catalogue » → Soins** : changer un titre, une description, une durée, remplacer la photo (bouton image).
4. **« 2 · Catalogue » → Rituels** : changer prix FCFA, contenu, cocher « mettre en avant ».
5. Cliquez **Publier** : le site se met à jour seul en ~1 min. Vous recevez la confirmation.

## Changer les photos (important !)
- Les 10 photos actuelles sont des visuels d'ambiance libres de droits, **à remplacer** par vos vraies photos (cabines, équipe, façade, produits).
- Envoyez 15–20 photos verticales/horizontales nettes sur WhatsApp au développeur pour la mise en ligne initiale.
- Ensuite, remplacez vous-même via l'admin : chaque soin a son bouton photo.

## Réservations : comment ça marche
- Chaque bouton « Réserver » ouvre **votre WhatsApp** avec un message déjà écrit (« je souhaite un massage », « rituel Teranga Glow »...).
- Vous savez donc **quel soin** intéresse la cliente avant même de répondre.
- Le formulaire de contact fait pareil avec le nom + créneau.
- Phase 2 possible : calendrier avec créneaux + rappels auto J-1.
